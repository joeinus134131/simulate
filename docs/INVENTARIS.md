## Dukungan .ino dan serial
Semua komponen memakai wiring solver yang sama; .ino berjalan pada Uno dan membaca/menulis pin yang benar-benar terhubung. Tidak ada pemetaan LED/sensor palsu menurut urutan komponen.

Parser terpisah (tanpa eval/new Function) mendukung deklarasi scalar, setup/loop, fungsi dengan parameter/return, if/else, while, for, break, assignment, postfix ++/--, operator aritmetika/logika/bit, literal string/char, komentar. API: pinMode, digitalWrite/Read, analogWrite/Read, delay, millis/micros, map, constrain, min/max/abs, Serial.begin/available/read/peek/print/println/write. Serial.read mengembalikan byte atau -1; write menulis byte, input UTF-8, pilihan tanpa akhiran/newline/CRLF. Serial.begin diperlukan untuk print/write; UI menghalangi RX ketika baud berbeda. Baud tidak mensimulasikan timing UART fisik.

Semantik scalar masih angka JavaScript: pembagian integer dan overflow C++ tidak dimodelkan; const belum readonly. Tidak mendukung #include/#define, array, pointer, kelas, struct, cast, switch, ternary, prefix increment, overload, variadic atau library. Sintaks/fungsi tidak didukung menghasilkan error, bukan diabaikan. Serial.print format basis 2/8/16 tersedia; presisi float ala Arduino belum diimplementasi. Parser bukan compiler C++ lengkap.

Worker bisa diterminasi langsung saat Stop/restart sehingga delay lama tidak menghidupkan kembali rangkaian. Jeda mempertahankan state program. Loop dibatasi 50.000 operasi per loop/delay, kedalaman panggilan 32, RX 4096 byte, sketch 64 KB. Log maksimal 500 chunk (tiap chunk maksimal 16 KB). Maksimum proyek 100 komponen/500 kabel; solver 256 net aktif. Floating net memakai referensi lemah deterministik, bukan noise fisik.

## Referensi Diode
[withdiode.com](https://www.withdiode.com/) ditemukan sebagai situs yang menjelaskan build/program/simulate hardware di browser. Saat diperiksa langsung 13 September 2026 situs menampilkan **Deployment Paused**. Karena itu fitur wiring/code/serial Diode tidak diuji dan tidak dijadikan bukti kemampuan runtime. Arah UX proyek tetap satu ruang kerja rangkaian + program + serial, tanpa menyalin aset situs itu.

## Penerimaan bentuk fisik
Ukuran utama dan kontrak pin telah diperbaiki, tetapi kriteria pengguna **sama dengan perangkat nyata** belum boleh dinyatakan selesai: detail yang disederhanakan di tabel masih terbuka. Model ini belum lulus overlay CAD/foto kalibrasi terhadap seluruh varian. Tampilan atas/depan/perspektif dan panel rujukan tersedia untuk evaluasi lanjutan.

**Runtime** (`src/lib/simulation/simulation.worker.ts`): **satu** Web Worker; simulation clock fixed-step 5 ms (200 Hz) dan frame UI rata-rata 60 Hz; solver DC kuasistatik — Gaussian elimination, ≤256 net aktif, referensi floating-net deterministik (1e-10 S). Akses HTTP langsung dari sketch diblokir; Wi-Fi/HTTP hanya kompatibilitas virtual. Servo punya state per objek sketch dan routing melalui net listrik. Sebagian shim peripheral lain (Stepper, OLED, LCD, DHT, HC-SR04) tetap emulasi ringkas; dukungan bus/I2C/SPI fisik dan CPU cycle-accurate belum tersedia.

**Implikasi untuk roadmap**: refactor **V-HAL per-instance** (satu state per komponen, addressed by pin) adalah prasyarat Fase 1 — tanpa ini robot multi-servo/multi-stepper tidak mungkin dibangun.

**Sudah selesai (tidak perlu dijadwalkan ulang)**: WebSerial flashing — `avrFlasher.ts` (AVR), `espFlasher.ts` (ESP32 via esptool-js), `webSerial.ts` (port picker + progress).

### Implementasi Physical AI (5 Oktober 2026)
- Katalog saat ini memiliki 34 tipe dengan **EduArm-3DOF**, **AeroArm-6DOF**, **RoverBot-4WD**, encoder incremental A/B, A4988, L298N, motor DC gearbox, catu DC, regulator buck-boost, battery pack OCV/ESR/SoC/proteksi, charger CC/CV, RGB-D, LiDAR planar, dan IMU 6-axis. Kedua lengan robot memiliki slider joint dalam derajat, target XYZ dalam meter, FK PoE, dan IK DLS di worker. AeroArm memakai model articulated 6R dengan tiga joint wrist dan batas sudut URDF-lite. Rover mengintegrasikan kecepatan roda kiri/kanan, pose, heading, dan fase roda dengan fixed timestep 5 ms serta menyediakan gimbal pan/tilt.
- Runtime kinematika menyediakan SO(3)/SE(3), PoE FK, Jacobian space/body, DLS pose dan posisi, FABRIK, serta trajectory quintic. Golden set 10⁴ pose terhadap chain analytic, 10⁴ round-trip exp/log SE(3), dan cek Jacobian finite-difference lulus. Benchmark lokal DLS pose max 1.755 ms/posisi max 0.908 ms dalam 1.000 target. Skrip perbandingan ModernRoboticsPython disiapkan, tetapi belum bisa dijalankan karena dependensi belum tersedia di lingkungan.
- Simulation clock fixed step 5 ms dan akses HTTP langsung dari sketch telah dinonaktifkan. V-HAL menelusuri sinyal Servo SG90 melalui wire, jumper, breadboard row/rail dan kontak komponen; Servo juga dapat dipasang di breadboard. `analogWriteResolution()` memakai kuantisasi 8-bit di Uno dan 8–16-bit di ESP32, dengan duty cycle diubah menjadi tegangan rata-rata untuk solver DC. `DifferentialDrive` menggerakkan RoverBot saat sim berjalan. Encoder menghasilkan count x4 dan level A/B GPIO; panel dapat mengopel sudut 1:1 ke motor stepper/DC dan sketch menerima edge melalui `attachInterrupt` (Uno D2/D3, ESP32 GPIO valid). Battery pack OCV/ESR memasok beban SG90/A4988/L298N/regulator buck-boost, mengintegrasikan SoC dan dapat memicu BOR pada rail eksternal. A4988 menggerakkan NEMA17 dan memodelkan current-limit, UVLO/OCP serta thermal shutdown; L298N mengendalikan motor DC R-L/back-EMF dengan dinamika fixed-step, diode clamp, dan RC thermal shutdown. Rapier worker opt-in menangani free-body box collider, gravitasi/lantai, friction/restitution dan fixed/revolute/prismatic constraint; batasnya collider generik, belum mesh-aware dan belum menerima torsi aktuator. Servo/Stepper/DC joint coupling masih kinematik tanpa dinamika link. RGB-D, LiDAR, dan IMU mengirim snapshot ke simulation worker dan sketch API numerik; Python subset V-SBC berjalan pada worker Pyodide, Wire I2C mendukung ACK berbasis wiring/power, dan AI Gateway menyediakan frame/action-chunk WebSocket. Panel ONNX menjalankan classifier lokal satu input Float32 RGB rank-4 pada worker dengan WebGPU/WASM dan top-k skor; deteksi objek serta verifikasi browser masih terbuka. Belum ada V4L2 atau test worker-browser end-to-end. DC supply tetap ideal; belum ada proteksi arus internal battery/charger sesuai hardware, regulator onboard MCU, chopper PWM cycle-accurate, atau limit arus catu. Lihat status validasi di `docs/RENCANA.md`.
